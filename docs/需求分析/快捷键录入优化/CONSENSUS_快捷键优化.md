# 共识文档：快捷键录入优化

> 文档版本：v1.0
> 创建时间：2026-02-26
> 状态：已确认

## 1. 明确需求描述

### 1.1 功能目标
优化快捷键配置页面的录入交互体验，实现：
1. **点击激活机制**：用户必须主动点击编辑区域后才激活键盘监听
2. **视觉反馈**：激活后显示荧光背景提示，明确告知用户可以录入快捷键

### 1.2 用户场景
- 管理员进入系统管理 → 快捷键配置页面
- 点击某个快捷键的"修改"按钮，打开模态框
- 模态框打开后，编辑区域默认不监听键盘
- 用户点击编辑区域，区域显示荧光效果，提示"已激活，请按下快捷键"
- 用户按下快捷键组合，系统捕获并显示
- 用户点击确认保存

## 2. 技术实现方案

### 2.1 核心逻辑变更

**状态管理**：
```typescript
// 新增状态
const [isActivated, setIsActivated] = useState(false); // 是否已点击激活
```

**事件监听逻辑变更**：
- 原逻辑：模态框打开即全局监听 `window.addEventListener('keydown', ...)`
- 新逻辑：
  1. 模态框打开时，`isActivated = false`，不监听键盘
  2. 用户点击编辑区域，`isActivated = true`，开始监听键盘
  3. 捕获到快捷键后，`isActivated = false`，停止监听

### 2.2 视觉设计方案

**未激活状态**：
- 边框：虚线边框 `2px dashed rgba(0, 212, 255, 0.3)`（暗黑）/ `#d9d9d9`（明亮）
- 背景：透明
- 提示文字："点击此处激活，然后按下快捷键..."

**已激活状态（荧光效果）**：
- 边框：实线边框 `2px solid #00d4ff`
- 背景：`rgba(0, 212, 255, 0.1)` 半透明青色
- 阴影：`0 0 20px rgba(0, 212, 255, 0.3)` 荧光光晕效果
- 提示文字："已激活，请按下快捷键..."
- 动画：添加脉冲动画效果增强视觉反馈

**捕获成功状态**：
- 保持现有逻辑，显示快捷键和验证结果

### 2.3 代码变更范围

修改文件：[ShortcutConfigPage.tsx](file:///d:/自动化测试平台/AITestCraft-Tech-style/frontend/src/pages/admin/ShortcutConfigPage.tsx)

变更内容：
1. `KeyCaptureModal` 组件内新增 `isActivated` 状态
2. 修改 `useEffect` 监听逻辑，仅在 `isActivated` 为 true 时监听
3. 编辑区域 `div` 添加 `onClick` 处理函数
4. 编辑区域样式根据 `isActivated` 状态动态变化
5. 模态框关闭时重置 `isActivated` 状态

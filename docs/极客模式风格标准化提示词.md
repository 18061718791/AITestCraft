# 极客模式（Geek Mode）风格标准化提示词

> **版本**: v1.0  
> **适用项目**: AITestCraft 自动化测试平台  
> **目标**: 将经典模式扩展为支持双模式切换（经典/极客）+ 暗色系炫彩效果

---

## 一、需求背景与目标

### 1.1 原始需求
- 平台最初仅支持经典模式（传统亮色主题）
- 需要扩展为支持双模式切换：经典模式 + 极客模式
- 极客模式需要具备暗色系下的炫彩视觉效果

### 1.2 设计目标
- **科技感**: 赛博朋克风格，霓虹发光效果
- **可切换**: 用户可自由切换经典/极客模式
- **一致性**: 双模式下保持交互逻辑一致
- **性能**: 动画效果流畅，不影响页面性能

---

## 八、颜色系统

### 8.1 标签颜色配置

```typescript
/**
 * 8种预设颜色用于任务窗口区分
 * 每种颜色都有良好的视觉区分度，不使用红色（太刺眼）
 */
export const TAB_COLORS = [
  '#00d4ff', // 青色 - 清爽科技
  '#10b981', // 翠绿 - 生机勃勃
  '#f59e0b', // 琥珀 - 温暖活力
  '#8b5cf6', // 紫色 - 神秘优雅
  '#ec4899', // 粉色 - 活泼明快
  '#3b82f6', // 蓝色 - 稳重专业
  '#14b8a6', // teal - 清新自然
  '#f97316', // 橙色 - 活力热情
] as const;

/**
 * 根据ID获取随机颜色（保持一致性）
 */
export function getRandomColorById(id: string): string {
  let hash = 0;
  for (let i = 0; i < id.length; i++) {
    hash = id.charCodeAt(i) + ((hash << 5) - hash);
  }
  const index = Math.abs(hash) % TAB_COLORS.length;
  return TAB_COLORS[index];
}
```

## 十一、调优经验总结

### 11.1 视觉效果调优

| 调优项 | 原始方案 | 最终方案 | 原因 |
|-------|---------|---------|------|
| 背景色 | 纯黑 #000 | 深蓝灰 #0f172a | 减少视觉疲劳 |
| 主色调 | 亮蓝 #1890ff | 青蓝 #00d4ff | 更具科技感 |
| 边框发光 | 单层 | 双层旋转 | 增强流光效果 |
| 标签形状 | 矩形 | 八边形切角 | 更具未来感 |
| 提示条 | 矩形 | 梯形 | 引导视觉聚焦 |

### 11.2 性能优化

1. **动画优化**: 使用 `transform` 和 `opacity` 代替 `width/height`
2. **渲染优化**: 使用 `will-change` 提示浏览器优化
3. **减少重绘**: 避免频繁修改 `box-shadow`
4. **GPU加速**: 使用 `translate3d` 开启硬件加速

### 11.3 可访问性

1. 保持足够的颜色对比度
2. 提供减少动画选项
3. 支持键盘导航
4. 适配高对比度模式

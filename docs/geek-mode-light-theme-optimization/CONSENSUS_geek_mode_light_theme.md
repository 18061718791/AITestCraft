# 极客模式亮色系优化 - 需求共识文档（修订版）

## 需求描述

优化极客模式下的亮色系配色方案，解决当前青色 `#00d4ff` 在亮色背景下过于刺眼的问题，同时保持极客风格的科技感和未来感。

**关键要求**: 采用真正的亮色系（浅色背景），而非暗色系。

## 技术实现方案

### 方案选择: 极客亮色系（真正的浅色背景）

#### 核心设计思路
采用**浅灰/白色基调**作为背景，通过以下方式保持极客风格：
1. 使用深色主色调（而非亮色）来避免刺眼
2. 保留科技感的几何元素和发光效果（适度）
3. 使用蓝紫色调体现科技感
4. 采用渐变和微妙的霓虹效果

### 颜色系统定义

| 用途 | 原值 | 新值 | 说明 |
|-----|------|------|------|
| 主色 Primary | `#00d4ff` | `#2563eb` | 从天青色调整为**深蓝**，在亮色背景下更协调 |

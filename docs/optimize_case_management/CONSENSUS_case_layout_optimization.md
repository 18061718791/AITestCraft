# 测试用例管理页面布局优化 - 共识文档

## 最终需求描述

### 核心需求
1. **增大编辑模态框宽度**：从800px增加到1000px，提供更宽敞的编辑空间
2. **步骤与结果并行布局**：测试步骤和预期结果在同一行显示，采用6:4比例分配空间
3. **同步优化查看页面**：详情查看弹窗也采用类似的并行布局
4. **保持响应式特性**：确保在不同屏幕尺寸下都能正常显示

### 验收标准

#### 编辑页面优化
- [ ] 模态框宽度从800px调整为1000px
- [ ] 测试步骤和预期结果字段在同一行显示
- [ ] 步骤区域占60%宽度，结果区域占40%宽度
- [ ] 保持现有的表单验证和功能逻辑
- [ ] 文本域高度自适应，确保良好的编辑体验

#### 查看页面优化
- [ ] 详情弹窗宽度从650px调整为900px
- [ ] 测试步骤和预期结果采用并行卡片布局
- [ ] 保持信息的清晰展示和良好的可读性
- [ ] 维持现有的状态、优先级标签样式

#### 用户体验标准
- [ ] 编辑时可以清晰对照步骤和预期结果
- [ ] 查看时可以直观对比步骤与结果
- [ ] 保持界面美观和专业的视觉效果
- [ ] 确保在不同分辨率下的可用性

## 技术实现方案

### 编辑模态框优化
```tsx
// 宽度调整
width={1000}

// 步骤与结果并行布局
<Row gutter={16}>
  <Col span={14}>
    <Form.Item label="测试步骤" name="steps">
      <TextArea rows={6} />
    </Form.Item>
  </Col>
  <Col span={10}>
    <Form.Item label="预期结果" name="expectedResult">
      <TextArea rows={6} />
    </Form.Item>
  </Col>
</Row>
```

### 查看详情优化
```tsx
// 宽度调整
width={900}

// 并行卡片布局
<Row gutter={16}>
  <Col span={14}>
    <Card title="测试步骤" size="small">
      <pre style={{ margin: 0, whiteSpace: 'pre-wrap' }}>
        {testCase.steps}
      </pre>
    </Card>
  </Col>
  <Col span={10}>
    <Card title="预期结果" size="small">
      {testCase.expectedResult}
    </Card>
  </Col>
</Row>
```

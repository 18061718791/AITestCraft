注意：这个测试用例模拟了全局的 `* { background-color: inherit; }` 样式

问题分析

如果 .ant-select-selection-item 没有 background-color，灰色背景可能来自：

  • 1. .ant-select-selector 的默认背景色
  • 2. .ant-select-selection-search 的默认背景色
  • 3. 父元素的背景色通过 inherit 继承
  • 4. Ant Design 的默认样式
  • 5. 浏览器默认样式

解决方案

需要在 CSS 中明确设置以下元素的背景色：

.dark .ant-select-selector {
  background-color: #1e293b !important;
}

.dark .ant-select-selection-item {
  background-color: #334155 !important;
}

.dark .ant-select-selection-search {
  background-color: transparent !important;
}

## 修复方案

### 核心修改
修改 `statisticsService.ts` 中的 `getAllChildDirectoryIds` 方法，实现正确的统计逻辑：

**修改逻辑：**
- 当二级目录（系统）下有三级目录（模块）时，只返回三级目录ID，排除二级目录ID
- 当二级目录下没有三级目录时，返回二级目录ID本身

### 修改文件
1. **backend/src/services/statisticsService.ts** - 修改 `getAllChildDirectoryIds` 方法

### 修改内容
```typescript
private async getAllChildDirectoryIds(parentId: string | number, includeLevel2: boolean = true): Promise<number[]> {
  const parentIdStr = String(parentId);
  const childDirectories = await prisma.directories.findMany({
    where: {
      parent_id: parentIdStr
    }
  });

  let allChildIds: number[] = [];

  for (const dir of childDirectories) {
    const dirId = parseInt(dir.id);
    const dirLevel = dir.level;
    
    // 递归获取孙子目录
    const grandChildIds = await this.getAllChildDirectoryIds(dir.id, includeLevel2);
    
    if (!includeLevel2 && dirLevel === 2) {
      // 跳过level=2的目录，但仍然递归处理其子目录
      allChildIds = [...allChildIds, ...grandChildIds];
    } else if (dirLevel === 1 && grandChildIds.length > 0) {
      // 关键修复：二级目录下有三级目录时，只使用三级目录ID，排除二级目录ID
      allChildIds = [...allChildIds, ...grandChildIds];
    } else {
      // 二级目录下没有三级目录，或者需要包含level=2的目录
      allChildIds.push(dirId);
      allChildIds = [...allChildIds, ...grandChildIds];
    }
  }

  return allChildIds;
}
```

# 极客模式亮色系优化 - 需求对齐文档

## 项目背景

### 当前状态
AITestCraft 自动化测试平台支持双模式切换：
- **经典模式 (light)**: 传统亮色主题，使用清爽蓝色 `#1890ff` 作为主色调
- **极客模式 (dark)**: 赛博朋克风格，使用青蓝色 `#00d4ff` 作为主色调，配合霓虹发光效果

### 问题描述
当前极客模式在亮色主题下存在颜色协调性问题：
1. **主色调冲突**: 白色/浅色背景上使用青色 `#00d4ff` 作为主色调，对比度过高显得刺眼
2. **缺乏层次感**: 亮色背景下的赛博风格元素缺乏视觉层次
3. **发光效果不协调**: 霓虹发光效果在亮色背景下显得突兀
4. **整体风格不统一**: 极客风格的科技感与亮色背景的简洁感存在冲突

## 原始需求

> 目前极客模式下的亮色系，各个颜色的使用不够协调，就如使用白色作为主色调，这个时候的青色就会显得很刺眼，请帮我将极客模式下的亮色系进行整体调整，显示更协调一些，但一定是符合极客风格

## 需求理解

### 核心诉求
1. **保持极客风格**: 必须保留科技感、未来感的视觉特征
2. **优化亮色系**: 调整颜色搭配，使亮色背景下的极客模式更加协调
3. **降低刺眼感**: 解决青色在白色背景上过于刺眼的问题
4. **提升视觉层次**: 建立清晰的视觉层次结构

### 边界确认
- **范围**: 仅调整极客模式下的亮色系配色方案
- **不涉及**: 
  - 暗色主题（dark）的修改
  - 经典模式（light）的修改
  - 布局结构调整
  - 功能逻辑变更
- **保留**: 所有动画效果、组件结构、交互逻辑

### 技术约束
- 使用现有主题系统（CSS Variables + Ant Design ThemeConfig）
- 保持与现有组件的兼容性
- 不引入新的依赖库

## 疑问澄清

### 已确认的设计方向
基于项目现有极客模式风格标准化文档，确定以下设计原则：

1. **极客风格核心元素必须保留**:
   - 霓虹发光效果（但需调整强度）
   - 流光边框动画
   - 科技感配色
   - 几何形状（八边形、梯形等）

2. **亮色系极客模式的设计策略**:
   - 使用深色/饱和度较低的主色调替代亮青色
   - 采用渐变背景替代纯白背景
   - 调整发光效果的透明度和扩散范围
   - 引入科技感的中性色作为辅助

## 设计方向建议

### 方案A: 深蓝科技风（推荐）
- 背景：深蓝灰渐变 `#0f172a` → `#1e293b`（保持暗色但降低对比）
- 主色：电光蓝 `#3b82f6` 或科技蓝 `#0ea5e9`
- 强调色：保留青色但降低饱和度 `#06b6d4`
- 特点：保持科技感，视觉更舒适

### 方案B: 灰白科技风
- 背景：浅灰蓝 `#f1f5f9` 或冷灰 `#e2e8f0`
- 主色：深蓝 `#1e40af` 或靛蓝 `#4338ca`
- 强调色：青色 `#0891b2`
- 特点：更接近传统亮色，但保留科技元素

### 方案C: 暗黑科技风（微调）
- 背景：保持现有暗色 `#0f172a`
- 主色：降低青色亮度 `#0891b2`
- 强调色：蓝绿色系
- 特点：最小改动，仅降低刺眼感

## 建议采用方案A

理由：
1. 保持极客模式的暗色基调，这是赛博朋克风格的核心
2. 通过调整主色和强调色的饱和度，解决刺眼问题
3. 与现有暗色主题代码兼容性最好
4. 用户提到"亮色系"可能指的是相对现有暗色更亮的变体，而非纯白背景
